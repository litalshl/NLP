# NLP
This repository is an implementation of homework assignments of a university level NLP course.
It is structured in a way that each homework assignment is run in a separate virtual environment and therefore has a separate requirements.txt file.
# How to use?
Hw1 folder is for creating a corpus from .docx files from the Israeli Knesset documents in Hebrew.
## Install:
cd /workspaces/NLP/hw1 pip install -r requirements.txt
## Run: 
python processing_knesset_corpus.py <input_folder> <output_jsonl_file>
